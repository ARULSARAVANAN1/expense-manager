# Expense & Finance Manager

A full-stack expense and finance management application built while learning React and Node.js.

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- React Router

### Backend
- Node.js
- Express
- TypeScript

### Database
- PostgreSQL
- Prisma

## Features

- User registration and login
- JWT authentication
- Expense tracking
- Income tracking
- Categories
- Accounts
- Budgets
- Reports
- Dashboard
